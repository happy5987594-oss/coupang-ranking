# 사이트 설계도(PRD) — 쿠팡 해외구매대행 인기 상품 랭킹 (가제)

작성일: 2026-11-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
쿠팡 해외구매대행 인기 상품을 쿠팡 순위 그대로 모아, 알뜰하게 사려는 사람이 한눈에 비교하고 쿠팡으로 바로 가게 해 주는 랭킹 사이트.

## 2. 손님
- 누가: 해외 상품을 싸고 편하게 사고 싶은 알뜰한 소비자
- 어디서 알고 오나: 인스타그램·유튜브 게시물과 프로필 링크

## 3. 손님이 궁금한 것 (상품을 누르기 전에)
1. 가격·할인 — 지금 얼마인지, 싼 편인지
2. 왜 인기인지 — 순위가 높은 이유, 평점·리뷰 수
3. 배송 기간·관세 — 해외에서 오니까 며칠 걸리는지, 관세·반품은 어떤지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 순위 기준: 쿠팡에서 보이는 순위(판매량순·리뷰 수·평점)를 그대로 옮겨 적는다. 지어내거나 바꾸지 않는다.
- 순위·가격마다 "○월 ○일 쿠팡 기준"을 함께 적는다.
- 후기: (실제 후기가 생기면 넣는다. 지금은 자리만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 쿠팡에서 보기
- 누르면: 쿠팡 상품 페이지로 이동 (일반 링크, 쿠팡 파트너스 아님)

## 6. 페이지 구성 (위에서 아래로, 한 장짜리)
1. 첫 화면 — 한 문장 + "기준일" + 랭킹으로 내려가는 버튼
2. 인기 랭킹 목록 — 순위 · 상품 이름 · 가격 · 평점/리뷰 수 · 배송 예정 기간 · [쿠팡에서 보기]
3. 순위를 정하는 방법 — "쿠팡 순위를 그대로 옮겼어요" + 기준일 + 가격이 바뀔 수 있다는 안내
4. 해외구매대행 알아 두기 — 배송 기간·관세·반품은 상품마다 다르니 쿠팡 상품 페이지에서 확인하라는 짧은 안내
5. 후기 자리 (비워 둠)
6. 맨 아래 — 인스타·유튜브 링크

## 7. 문의 폼에서 받을 것
- 이번엔 문의 폼 없음 (손님 글을 받아 저장하지 않는다)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: (미정) — 쿠팡에 보이는 값을 그대로 옮기고 기준일을 적는다
- 순위: 쿠팡 순위 그대로
- 배송 기간·관세: (미정) — 쿠팡 상품 페이지에 적힌 그대로
- 연락 방법: (미정) — 인스타·유튜브 계정 주소

## 9. 이번에 넣지 않을 것
- 순위 자동 업데이트 (오늘은 직접 옮겨 적는 방식)
- 분야별 랭킹 (건강식품·뷰티·육아 등)
- 블로그·상품별 상세 리뷰 글
- 문의·상품 요청 저장, 관리자 페이지
- 회원가입·로그인, 결제

## 10. 첫 화면 한 문장 후보
1. 요즘 쿠팡에서 잘 팔리는 해외 상품, 순위대로 한눈에.
2. 해외직구 고민될 땐, 쿠팡 인기 순위부터 보세요.
3. 가격·평점·배송 기간까지, 해외구매대행 인기 상품을 한 장에.

## 11. 다음에 할 것
- 9번 목록을 하나씩 추가
- 랭킹에 넣을 실제 상품 목록 정리 (상품 이름 · 쿠팡 링크 · 가격 · 평점/리뷰 수 · 배송 기간 · 기준일)
- 상품 사진을 쓸 경우 쿠팡 이용 약관·사진 사용 가능 여부 확인

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 깔끔한 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 아니오 → 쿠팡 링크 버튼만
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. (9번이 '예'일 때만) 문의 폼 → Supabase 저장 → /admin — 이번엔 해당 없음
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제
- 상품 목록이 아직 없으면 랭킹 칸은 "준비 중"으로 두고, 상품 정보를 지어내지 않는다
